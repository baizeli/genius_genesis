说明：
- `20 tick = 1 秒`。
- 蓝耗按 Iron 法术常规公式理解：`baseManaCost + manaCostPerLevel * (等级 - 1)`。

## 需要注意的问题

| 法术 | 当前问题 |
| --- | --- |
| `blood_control` | 没有低血量保护，直接按最大生命百分比对施法者造成 `genericKill` 伤害，可能把自己杀死。 |
| `blood_frenzy` | tooltip 显示的 `damage_multiplier` 是 200/201/202，但真实伤害逻辑固定为造成伤害 x2；数值展示和实际逻辑不一致。自动攻击逻辑在客户端事件里触发，联机下需要重点测试。 |
| `confusion` | 持续时间没有使用 `getSpellPower`，而是直接用 `AttributeRegistry.SPELL_POWER` 除以 0.2；这和其他法术成长体系不一致。 |
| `siphon` | tooltip 写吸收/治疗，但效果类当前只每秒扣自己最大生命 2%，没有吸血或护盾逻辑。 |
| `blood_war` | 当前逻辑是临时不死，倒计时结束后非 hardcore 直接杀死玩家；这不是普通增益效果。 |
| `reverse_plague` | 依赖两个 Mixin 和静态 UUID 映射，逻辑较脆弱；换维度、实体卸载、服务端重启后的行为需要专门测。 |
